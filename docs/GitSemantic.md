# Git Semantic Commit

1. `feat`: Adiciona uma nova funcionalidade ao sistema.
2. `fix`: Faz a correção de um bug ou erro.
3. `docs`: Altera ou adiciona documentação (como no README).
4. `style`: Melhora a formatação do código (espaços, ponto e vírgula), sem mudar a lógica.
5. `refactor`: Faz uma reestruturação do código que não corrige erros nem cria funções.
6. `test`: Adiciona ou corrige testes automatizados.
7. `chore`: Atualiza tarefas de manutenção, dependências ou arquivos de configuração.
